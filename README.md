# Fog of War Observatory

A Unity space game for Windows. You fly a ship through a real-scale solar system and visit physics scenes that run on the real equations: a ray-traced black hole and wormhole, an Alcubierre warp bubble, a constant-1g relativistic trip, negative mass, tides from a closer Moon, terraforming Mars, and radio meteor scatter. Planet and sky maps come from NASA/USGS data.

## Open it

1. Install **Unity 6.6** (editor `6000.6.4f1`, see `ProjectSettings/ProjectVersion.txt`) through Unity Hub.
2. Clone this repo.
3. In Unity Hub, choose **Add → Add project from disk** and select the repo folder. The first import takes a while.
4. Use the **Fog of War** menu: **1. Create and open the sim scene**, then press Play.
5. To build: **Fog of War → 2. Build Windows game**. The game lands in `Builds/Windows/FogOfWar.exe`.
